# Hedgerow Planner

A browser-based tool for laying out hedgerow and garden plantings. Add plants as spacing circles, drag them into place on a scaled grid, then switch to a planting diagram with symbols and a key. Export the result as a PNG or PDF.

Built for the [Native Plant Salvage Foundation](https://donorbox.org/support-the-native-plant-salvage).

## Features

- Spacing diagram and planting diagram views, with a key grouped by layer
- Plant presets from the Native Plant Salvage Foundation, plus your own saved plant lists
- Custom layers, colors and patterns
- CSV import for plant lists
- Undo and redo, zoom, arrow-key nudging, auto ordering by size
- Saved layouts, and plan files for backing up or moving your work
- PNG and PDF export with title, notes, scale bar and compass

## Using it

Open the site and start adding plants. Everything is saved in your browser. To move your work to another browser or computer, use **Save plan file** and **Open plan file**.

## Running it yourself

The whole app is a single file, `index.html`. Open it in a browser, or host it anywhere that serves static files, such as GitHub Pages.
